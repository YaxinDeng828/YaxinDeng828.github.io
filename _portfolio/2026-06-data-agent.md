Built a DataAgent with an integrated planning, execution, verification, and correction architecture. The system understands CSV, JSON, SQLite, and unstructured documents, identifies target fields and cross-table relationships in advance, and uses DuckDB and Python for deterministic computation.

AnswerGuard and FeedbackReplanning address field misidentification, aggregation bias, missed extremes, and anomalous empty results. The system also supports direct result output, concurrent scheduling, end-to-end tracing, and Docker delivery.
